Community-centered language work

Work with Indigenous-language materials
with care, context, and accountability.

The Indigenous Languages Skill is a guided workflow for AI-assisted work involving Indigenous languages, language-learning materials, linguistic documentation, and community-sensitive research. It helps keep the task grounded in source context, appropriate evidence, and the limits of what an AI system should infer.

A practical workflow

How to use this skill

Give the agent a bounded task, enough context to assess it responsibly, and clear expectations for the final output.

  1. 01

    Start with a specific task

    State what you need: for example, a lesson activity, a source comparison, a morphology explanation, or a review of draft wording.

  2. 02

    Provide the relevant context

    Include the language or variety, source materials, intended audience, orthography, community guidance, and any limits on reuse or sharing.

  3. 03

    Set evidence and output standards

    Specify whether the answer should cite sources, preserve original wording, distinguish evidence from inference, or use a particular format.

  4. 04

    Review before relying on it

    Treat the result as a working draft. Verify language forms, cultural claims, permissions, and community-sensitive interpretations with appropriate sources or knowledge holders.

Example prompt

“Use the Indigenous Languages Skill to help me design a beginner lesson activity for [language]. Base it only on the sources I provide, preserve the supplied orthography, distinguish documented facts from proposed teaching choices, and flag anything that requires review by a fluent speaker or community authority.”
