Sleepy Cat
Rest easy.

Sleepy Cat is a browser-based wind-down tool built around a sleepy cat. It pairs guided breathing with eighteen rain and nature soundscapes, a looping cat purr, session and sleep timers, and a dim-screen mode for low-light use.

Breathing · soundscapes · timers

How to use it

  1. 01 Choose a quiet sound — gentle drizzle, rain on glass, a roof, canvas, forest canopy, ocean waves, or wind in pines.
  2. 02 Set a breathing rhythm: Easy at 4 in / 6 out, Long exhale at 4 in / 8 out, or Box breathing.
  3. 03 Add the cat purr, pick a session (5 / 10 / 20 min) or sleep timer (15 / 30 / 60 min), and dim the screen.
✦

Build note: the rain and nature beds are synthesised live in the browser with the Web Audio API rather than looped sample files, so each soundscape runs without a download; only the purr is a recording. Preferences persist locally.
