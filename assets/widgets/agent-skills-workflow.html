Reusable AI workflows

Give your agent
a repeatable way to work.

An agent skill is a reusable workflow that combines instructions, tools, context, and quality checks. It helps an AI agent perform a specific task consistently—without requiring you to explain the same process from scratch each time.

How to use a skill

Start with the workflow, then supply the details that are unique to your task.

  1. 01

    Choose a skill

    Select the workflow that best matches what you want to accomplish.

  2. 02

    Add your context

    Provide files, links, examples, constraints, or relevant material.

  3. 03

    Describe the outcome

    State the format, audience, depth, and standards for the result.

  4. 04

    Review and refine

    Check the output and iterate when new constraints or evidence arise.
